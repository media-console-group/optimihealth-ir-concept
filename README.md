# Optimi Health: investor-relations concept page

An independent investor-relations concept page for Optimi Health Corp. (Nasdaq: OPTH). It is built from the company's SEC filings and its public website. It is not affiliated with, endorsed by, or prepared on behalf of the company, and it is not investment advice. Verify every figure against the filings on SEC EDGAR before relying on it.

The page is a single self-contained `index.html` with a few local images. Open it directly or serve this folder.
